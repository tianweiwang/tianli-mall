# 验收矩阵

共 115 项用例，初始状态全部为 NOT RUN。实际结果只记录在 `records/<里程碑>/results.jsonl`，本文件不写结果。

- **阶段**：最早需要通过的里程碑。之后的每个里程碑都要回归此前所有阶段的自动化用例。标为"MS0a / MS0b"的用例分两部分：MS0a 验收旧格式部分，MS0b 验收 v2 部分。
- **层级**：见 [03-test-environment.md](03-test-environment.md) §1。"记录"表示由报告和 git 证据验收，不是自动化测试。
- 一条用例包含多个子场景时，逐个子场景记录；任一子场景没有运行，整条不能记 PASS。
- 新接口按 HTTP 状态码判断（401/403/404）；旧接口按业务码判断，并必须核对零副作用。
