# 体态评估与健康档案体系 · 总体设计

**用途：** 业务方案说明，供决策与需求确认。落地由独立的 OpenSpec change 承载。

**日期：** 2026-07-30　**状态：** 草案，待四项业务决策确认（见第九章）

---

## 一、为什么要做这件事

### 1.1 它解决三个层面的问题

这套系统不是"给商城加个功能"，它同时是**门店的成交工具、品牌的管理抓手、公司的核心资产**。三者共用一套数据，这是它值得优先投入的原因。

| 层面 | 现在的问题 | 这套体系提供什么 |
| --- | --- | --- |
| **门店成交** | 顾客不知道自己有什么问题，购买决策靠销售话术 | 用客观数据呈现问题，把"我需要吗"变成"我该改善到什么程度" |
| **顾客留存** | 一次性买卖，买完关系就断了 | 定期复评形成回访理由，改善数据支撑续费与加购 |
| **品牌管理** | 无法判断门店是否规范经营、产品是否真的有效 | 门店质量可量化对比，产品效果有真实数据反馈研发 |
| **公司资产** | 产品可被模仿，营销可被复制，无长期壁垒 | 效果数据集不可复制，支撑器械注册升级与技术叙事 |

### 1.2 数据资产的不可复制性

竞品可以在三个月内抄走产品外观、抄走营销话术、抄走加盟政策。**唯一抄不走的是数万名真实用户的前后效果数据。**

这类数据的价值随时间指数增长，且有明确用途：

- **注册升级**：临床数据支撑医疗器械等级提升，等级越高审批壁垒越高
- **技术叙事**：有真实证据 + 专利 + 论文，才能讲技术属性，而非消费品逻辑
- **产品迭代**：哪种方案对哪类体态问题更有效，只有数据能回答

**这是唯一一件"越早开始越值钱、且晚做补不回来"的事**——三年后想拿到三年的纵向数据，唯一的办法是三年前就开始。

## 二、核心设计原则

### 2.1 表述非医疗，数据达临床标准

这是整套设计的关键决策，也是最容易做错的地方。

| | 对外表述 | 数据标准 |
| --- | --- | --- |
| 用词 | 体态记录、形体变化、使用反馈 | — |
| 避免 | 诊断、治疗、矫正、疗效 | — |
| 测量协议 | — | 统一站姿、参照点、设备、距离 |
| 数据结构 | — | 结构化字段，可直接用于统计分析 |
| 元数据 | — | 时间、门店、操作人、设备全程留痕 |
| 知情同意 | — | 含未来研究用途授权 |

**为什么这样设计：** 若用宽松标准积累数据，等到要用于器械注册时会发现测量不标准、无研究授权，数据全部作废。反之，按临床标准采集但以非医疗方式表述，等资质到位后历史数据可直接升级使用。

**同意书必须一开始就包含研究用途条款，事后补签几乎不可能。**

### 2.2 配对数据优先于样本量

**一万人各测一次，不如一千人各测三次。**

单次评估只能说明"这个人现在什么状态"，没有价值。只有同一个人的前后对比（配对样本）才能说明"用了之后发生了什么变化"。

因此整套设计的重心不在评估工具本身，而在**让顾客回来复评的机制**。这是第五章「复评召回」被列为核心工作流的原因。

### 2.3 少而准，胜过多而乱

指标不是越多越好。多一个指标就多一处测量误差来源、多一份操作负担。

**宁可只测三项但每次都测准，不要测十项而每项都有偏差。** 不同门店、不同操作人测出的数据若不可比，积累三年也是废数据。

## 三、指标体系

### 3.1 四类数据，各有分工

```
┌─ 客观测量 ──── 可信度最高，用于效果论证
├─ 主观量表 ──── 顾客感受，用于沟通与满意度
├─ 依从性 ────── 使用行为，用于解释效果差异
└─ 影像记录 ──── 直观对比，用于门店转化与口碑
```

**客观测量**是数据资产的主体，**依从性**是让数据具备说服力的关键（见 6.3），**影像**是门店愿意配合录入的动力，**主观量表**成本最低但单独使用说服力弱。

四类必须同时采集——缺依从性，效果数据就无法回应"是否自然恢复"的质疑。

### 3.2 客观测量指标

**具体测哪几项需要产品技术团队确定，取决于产品作用机理。** 以下为常见的可标准化项，供讨论：

| 指标 | 单位 | 说明 |
| --- | --- | --- |
| 双肩高度差 | mm | 冠状面对称性 |
| 骨盆倾斜角 | ° | 骨盆水平度 |
| 颈椎前倾角 | ° | 头前伸程度 |
| 胸椎后凸角 | ° | 圆背程度 |
| 腰椎前凸角 | ° | 腰部曲度 |
| 脊柱侧向偏移 | mm | 铅垂线偏离 |
| 足弓/负重分布 | — | 若产品涉及下肢链 |

**选择原则：**
1. 与产品作用机理直接相关——产品改善不了的指标，测了只会证明无效
2. 可重复测量——同一人短时间内重复测，误差应小于预期改善幅度
3. 门店可执行——不依赖昂贵设备或专业判读

**指标一旦确定，改动成本极高**，因为历史数据将不可比。建议首版控制在 3–5 项，立住标准后再扩展。

### 3.3 主观量表

- **不适程度（VAS）**：0–10 分，采集主要不适部位
- **不适部位**：颈/肩/上背/下背/腰/髋，多选
- **影响程度**：对睡眠、工作、运动的影响，三级
- **自评满意度**：复评时采集

### 3.4 依从性数据

| 来源 | 数据 | 优先级 |
| --- | --- | --- |
| 用户打卡 | 每次使用记录、时长 | 首版可行 |
| 设备回传（IoT） | 真实使用时长、频次、完成度 | 后续，可信度最高 |
| 门店记录 | 到店服务次数 | 首版可行 |

**依从性是整套数据的说服力放大器。** 没有它，"平均改善 3.2mm"会被质疑；有了它，"高依从组改善 4.7mm、低依从组 1.1mm"能同时证明产品有效且效果与使用量正相关。

### 3.5 影像记录

三张标准照：正面、侧面、背面。

**标准化要求**（否则对比无意义）：
- 固定拍摄距离与相机高度
- 地面站位标记
- 背景参照网格
- 统一光照条件
- 统一着装要求（如紧身衣或指定部位裸露范围）
- 拍摄后自动叠加时间戳与门店水印

## 四、系统形态：嵌入四个层次，不做孤立模块

这套体系**不应作为独立菜单存在**。它必须嵌进现有工作流，否则会变成"额外负担"而被门店敷衍。

### 4.1 层次一：顾客档案中的体态时间线

位置：现有用户详情页新增 Tab。

呈现为**纵向时间线**而非列表，每次评估显示与上次、与首次的差值：

```
陈**  女 34岁      首评 2026-03-12    已评估 5 次    依从性 良好
────────────────────────────────────────────────────────
2026-07-28   第 5 次   西湖店 · 李技师 · 设备 TL-200
  肩高差    4 mm   ↓2 (较上次)   ↓9 (较首评)
  骨盆倾斜  2.1°   ↓0.4          ↓1.8
  颈前倾    12°    ↓1            ↓6
  不适评分  2/10   ↓1            ↓5
  本期使用  21 次 / 建议 20 次   ✓ 依从良好
  [对比照]  正面 · 侧面 · 背面
────────────────────────────────────────────────────────
2026-06-30   第 4 次   ...
```

**设计要点：** 差值必须直接显示，不能让门店自己算。改善用向下箭头与绿色，恶化用红色——门店和顾客都能一眼看懂。

### 4.2 层次二：门店端的复评召回工作流

**这是整套体系能否成立的关键，比评估工具本身更重要。**

门店工作台新增模块：

```
待复评顾客                                    12 人
  陈**    距上次 28 天   已到期     [发提醒] [约时间]
  王**    距上次 21 天   7 天后到期  [发提醒]
  李**    距上次 45 天   逾期严重    [电话跟进]
本月复评率  68%   目标 80%
```

**为什么它最重要：** 评估工具做得再好，若顾客不回来做第二次，就永远只有横截面数据。配对数据是全部价值所在，而顾客不会自觉回来——必须做成门店的日常任务。

**与预约功能对接：** 复评本身就是一种预约类型，共用时段与核销体系。

### 4.3 层次三：品牌方效果统计

位置：品牌方后台新增分析模块。

```
样本概况
  累计评估      12,486 次
  有效配对      3,842 人（完成 ≥2 次）      配对率 62%
  平均随访周期  74 天

平均改善（配对样本）
  肩高差 -3.2mm    骨盆倾斜 -0.8°    颈前倾 -4.1°    VAS -1.4

依从性分层对比  ← 最具说服力的一张图
  高依从组（≥80%）  n=1,204   肩高差 -4.7mm
  中依从组（50-80%） n=1,876   肩高差 -3.1mm
  低依从组（<50%）   n=762     肩高差 -1.1mm

周期曲线
  4 周 -1.2mm  →  8 周 -2.4mm  →  12 周 -3.2mm  →  24 周 -3.8mm

门店质量对比
  门店        评估规范率   复评率   平均改善   异常标记
  西湖店         98%        76%     -3.6mm      —
  武林店         94%        71%     -3.2mm      —
  滨江店         72%        43%     -6.8mm     ⚠ 需核查
```

**滨江店那一行是设计要点：** 改善幅度显著高于均值、但规范率与复评率偏低，这是典型的数据异常信号，需要核查是操作不规范还是数据造假。**统计模块必须能主动发现异常，而不只是呈现平均值。**

### 4.4 层次四：研究导出接口

去标识化导出，供注册申报与研究使用。平时不用，但必须具备。

导出内容：结构化测量数据 + 依从性 + 人口学特征（年龄段、性别），**不含姓名、手机号、照片、门店身份**。导出行为本身需留痕。

## 五、三个角色的使用场景

同一套数据，三个角色的用法完全不同。**设计必须同时满足三者，否则某一环会失去配合动力。**

### 5.1 门店：成交与续费工具

这是让门店愿意认真录数据的**唯一理由**。若只为品牌方攒数据，门店必然敷衍。

| 场景 | 用法 |
| --- | --- |
| **首次到店** | 免费体态评估作为引流；测出客观问题，将"我需要吗"转为"改善到什么程度" |
| **方案推荐** | 依据评估结果匹配产品型号与使用方案，而非凭话术推销 |
| **复评转化** | 数据改善 → 续费、加购、转介绍顺理成章；数据未改善 → 正好调整方案 |
| **口碑素材** | 对比照经顾客授权后可用于分享 |

**配套设计：** 评估完成后自动生成**顾客可分享的报告**（去除敏感信息），既是门店转化工具，也是品牌获客渠道。

### 5.2 品牌运营：门店管理与产品迭代

| 用途 | 具体做法 |
| --- | --- |
| **门店质量管控** | 评估规范率、复评率、数据完整度纳入加盟商考核 |
| **产品效果验证** | 不同型号、不同方案的效果差异，反哺研发 |
| **异常预警** | 改善数据显著偏离均值、或规范率与改善率背离，触发核查 |
| **培训依据** | 操作规范率低的门店定向培训与复认证 |

### 5.3 管理层：融资与注册叙事

| 用途 | 数据支撑 |
| --- | --- |
| **投资人沟通** | 样本量 + 配对改善 + 依从性正相关，构成"有真实证据的正脊产品"叙事 |
| **器械注册升级** | 积累的临床数据支撑等级提升申请 |
| **专利与论文** | 真实世界数据支撑技术主张 |
| **单店模型** | 评估转化率、复评带动的复购率，是单店经济模型的组成部分 |

## 六、数据可信度设计

数据要能对外使用，可信度必须在采集阶段就保证。事后无法补救。

### 6.1 防造假机制

业绩压力下美化数据是真实风险，**一旦发生整个数据集失去价值**。

| 措施 | 作用 |
| --- | --- |
| 评估绑定时间、门店、操作人、设备编号 | 可追溯到责任人 |
| 照片自动叠加时间戳与门店水印 | 防止复用旧照 |
| 照片要求现场拍摄，限制相册上传 | 防止伪造 |
| 同一顾客两次评估的最小间隔限制 | 防止刷次数 |
| 测量值超出生理合理范围时告警 | 拦截明显错误 |
| 改善幅度异常时标记复核 | 发现系统性偏差 |
| 修改评估记录留完整审计日志 | 事后可查 |

### 6.2 测量标准化

**这是数据能否使用的分水岭。**

- **统一测量协议**：站姿、参照点、设备型号、测量顺序，形成书面 SOP
- **拍照辅助**：地面站位标记、背景网格、固定距离与相机高度
- **操作人认证**：培训 + 考核 + 定期复认证，未认证不能录入
- **设备校准**：记录设备编号与校准日期
- **重复性验证**：定期抽查同一顾客短时间内重复测量的一致性

### 6.3 依从性是说服力的核心

只报告平均改善，会遭遇三类质疑：自然恢复、安慰剂效应、样本选择偏差。

依从性分层对比能同时回应：**如果改善与使用量正相关，就很难用自然恢复或安慰剂解释。** 这是整套数据中最有价值的分析维度，因此依从性采集不可省略。

## 七、合规要求

体态与健康数据属于《个人信息保护法》下的**敏感个人信息**，合规不是附加项。

| 要求 | 具体做法 |
| --- | --- |
| **单独同意** | 独立于用户协议的知情同意，明确采集范围、用途、存储期限 |
| **研究用途授权** | 同意书含未来研究、注册申报用途条款——**事后补签不可行** |
| **最小化采集** | 只采集与产品相关的必要指标 |
| **加密存储** | 照片与测量数据加密，密钥独立管理 |
| **权限隔离** | 门店只能访问本店顾客；跨店访问阻断 |
| **访问留痕** | 谁在何时查看了谁的档案，全部记录 |
| **顾客权利** | 可查看、导出、删除自己的档案 |
| **去标识化导出** | 研究用途导出不含身份信息 |
| **照片特殊保护** | 涉及身体部位，权限更严、留痕更细 |

**若未来用于器械注册或学术发表，还需伦理审查与研究方案备案。** 具体要求需法务与注册顾问确认。

## 八、实施路径

按"数据价值 × 实施成本"排序，不按功能重要性。

### 第一阶段：立住标准（首版）

目标是**开始积累可用数据**，功能可以简陋，标准不能将就。

- 确定 3–5 项客观指标与测量 SOP
- 知情同意书（含研究用途授权）
- 评估录入 + 三张标准照 + 元数据留痕
- 顾客档案时间线与差值展示
- 待复评列表与提醒
- 顾客可分享报告
- 权限隔离与访问留痕

**暂不做：** AI 自动测量、复杂统计、3D 建模。先用人工把标准立住，标准稳定后再自动化。

### 第二阶段：形成闭环

- 依从性采集（打卡，条件成熟接设备回传）
- 品牌方效果统计与依从性分层
- 门店质量对比与异常预警
- 操作人认证体系
- 与预约功能对接，复评纳入预约类型

### 第三阶段：转化为资产

- 数据质量治理与重复性验证
- 去标识化研究导出
- 数据整理支撑注册申报、专利、论文
- 效果数据反哺产品迭代与方案优化

## 九、需要业务方确认的四项决策

**这四项不定，无法进入设计。前两项尤其关键——它们决定整套体系的形态。**

### 1. 测量哪几项客观指标

由产品技术团队确定，取决于产品作用机理。**指标确定后改动成本极高，历史数据将不可比。** 建议首版 3–5 项。

### 2. 产品的医疗器械分类与表述红线

需注册顾问或医疗器械法规顾问判断。决定：能否使用"评估""改善"等表述、宣传口径边界、是否需要伦理审查。

### 3. 门店是否具备专业评估资质

若门店提供正脊手法服务，可能需要医疗机构执业许可。**门店无证经营的责任会传导至品牌方。** 决定门店做"专业评估"还是"非医疗体态记录"。

### 4. 知情同意书范围

需法务出具。核心是**是否包含未来研究与注册申报用途**——这一条决定数据未来能否用于最有价值的场景。

## 十、与其他工作的关系
