# 区域代理结算 Demo

## Why

当前 Demo 只有门店与品牌两方分账，现有个人分销表示消费者分享关系，无法表达负责招商和管理加盟门店的区域代理，也无法展示特色系列、经典系列按门店 50%、集团 35%、代理 15% 结算的最新口径。

## What Changes

- 新增独立区域代理档案及门店代理归属，不复用个人分享绑定。
- 特色系列、经典系列的会员本金项目结算保存代理及比例快照，并生成三方模拟品牌分账。
- 集团直营门店按门店 50%、集团 50% 结算。
- 赠送积分项目结算保存零现金快照，不生成待处理现金分账。
- 品牌后台新增区域代理列表和详情，并从门店、订单或项目结算、分账页面双向追溯。
- 扩展模拟分账失败与重新处理状态，保持完成操作幂等。
- 明确个人分享佣金由集团推广预算承担，与代理分账和客户补贴资金池分开显示。

## Capabilities

### New Capabilities

- `regional-agent-settlement-demo`: 区域代理档案、门店归属、适用项目三方结算及品牌后台追溯闭环。

### Modified Capabilities

None. 本变更只扩展独立 H5 Demo，不修改正式 CRMEB 能力。

## Impact

- 修改 `demo/franchise-platform-h5` 的本地种子、会员项目结算、分账状态、选择器、品牌与门店页面和测试。
- 新增区域代理领域模块、品牌路由和两张品牌页面。
- 不新增真实支付、微信分账、数据库、代理端、代理提现或代理进件。
