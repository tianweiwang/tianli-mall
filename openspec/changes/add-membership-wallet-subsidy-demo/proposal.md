# 会员储值与补贴 Demo 闭环

## Why

当前 Demo 只有全局积分展示，没有按客户隔离的会员、储值本金、赠送积分或补贴账户，也无法演示客户开卡、门店结算和品牌补贴之间的因果关系。

## What Changes

- 新增 510 元会员卡和 5100 元储值方案的模拟购买流程。
- 将积分和会员资产按客户隔离，支持本金、积分、补贴、权益及流水。
- 让商品订单和门店项目结算执行已确认的会员价格规则。
- 将线上预约、门店核销、项目结算和补贴消费累计连接起来。
- 新增品牌会员运营页面和每周补贴批次。
- 用跨角色浏览器流程证明品牌发放后客户账户立即到账。

## Capabilities

### New Capabilities

- `membership-wallet-subsidy-demo`: 会员开卡、储值、项目结算、资产流水和每周补贴三端闭环。

### Modified Capabilities

None. 本变更只扩展独立 H5 Demo，不修改正式 CRMEB 能力。

## Impact

- 修改 `demo/franchise-platform-h5` 的本地种子、状态转换、选择器、路由、三端页面和测试。
- 不新增真实支付、接口、数据库、定时任务、补贴支付或提现。
