# Design: 分享分销归因 Demo

## State ownership

`shareLinks.js` 只生成部署安全的路径和 URL。`transitions.js` 负责分享活动、访问、绑定、订单、奖励、佣金、结算和提现状态。`selectors.js` 为页面关联数据。Vue 组件不直接修改财务字段。

## Attribution

令牌化分享最多创建一个有效本地绑定。首次有效绑定持续作用于后续订单，其他令牌不能静默覆盖。普通订单没有分销归因，也不产生佣金。

接受推荐后，当前消费者身份切换到绑定中的好友。好友用户中心从当前绑定读取推荐人、绑定状态和首单状态；分销员的分享、邀请和佣金数据仍由原分销员持有，好友用户中心不提供这些管理入口。

演示导航器只列出分享人和已经通过分享绑定的好友。切换消费者时同步恢复该消费者自己的有效绑定；没有绑定的分享人不继承好友归因。种子订单归属于分享人，新订单记录当前消费者，消费者订单列表、详情和支付结果只读取当前账号的数据，门店端和品牌端仍读取全平台订单。

分销中心的“我的团队”统计复用消费者端现有推荐明细页。整张团队卡片作为单一导航入口，不复制成员列表和状态映射。

## Financial behavior

归因订单使用分销员档案的 8% 比例创建一条待结算佣金。首单另发一次 800 分推荐奖励。完成订单分账时结算匹配佣金；门店收入不变，分销成本只减少品牌抽成净额。

## Idempotency

同一浏览器对同一令牌的访问去重。重复接受返回现有绑定。`paymentAttemptId` 防止重复订单、积分、佣金和奖励。分账状态转换校验防止重复结算。

## UI

消费者链路覆盖分享生成、二维码/链接、好友落地、接受推荐、好友用户中心归属、确认订单和支付反馈。品牌订单、分账详情、分销管理和提现审核展示对应归因与资金状态。
